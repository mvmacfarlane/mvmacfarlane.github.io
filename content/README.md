# Content Management

This folder contains all the content for your website. You can edit these files directly to update your website content.

## Files:

- `welcome.md` - Main welcome section content
- `about.md` - About me section content  
- `news.md` - All news items (chronologically ordered)
- `timeline.md` - Professional timeline/education
- `contact.md` - Contact information
- `publications.md` - All publications with details
- `software.md` - Open source software projects

## How to update:

1. Edit the relevant `.md` file
2. The content will be automatically included in the HTML pages
3. For news, add new items at the top (most recent first)
4. For publications, add new papers in the appropriate year section

## Content Structure:

- Use `#` for main headings
- Use `##` for subheadings  
- Use `**bold**` for emphasis
- Use `-` for bullet points
- Use `**Authors:**`, `**Venue:**`, etc. for publication details
